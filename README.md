# 📄 Dynamic A4 Resume Builder

A fast, fully responsive, client-side resume builder built with **React** and **Vite**. It generates a professional, clean single-page software engineer resume optimized for A4 paper with real-time editing and active clickable hyperlinks in exported PDFs.

---

## ✨ Features

* **⚡ Real-Time Live Preview:** Instant two-way binding updates the resume layout as you type.
* **🎯 Exact Single-Page A4 Calibration:** Carefully tuned typography and line heights ensure your resume occupies ~95% of an A4 page without overflowing to a second page.
* **🔗 Clickable Links in PDF:** Preserves active hyperlinks for LinkedIn, GitHub, LeetCode, and email addresses inside the generated PDF.
* **🚫 Zero Backend Dependency:** 100% pure client-side processing using `html2pdf.js`—no database or server required.
* **📱 Responsive Layout:** Split-pane desktop view with responsive collapsible layout for smaller screens.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React (Vite)
* **Styling:** Pure CSS (Print & A4 Media Queries)
* **PDF Engine:** `html2pdf.js`
